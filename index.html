How to Play Perspective

TILE REFERENCE (VALUES 1–15)

4-Bit Binary Dot System

Each tile contains 1 to 4 dots representing a binary number from 1 to 15 based on relative orientation:

  • Top Dot = 1
  • Right Dot = 2
  • Bottom Dot = 4
  • Left Dot = 8

Combining dot positions gives values from 1 to 15 (e.g., Top + Right = 1 + 2 = 3).

Goal

Score points by placing tiles on the grid to create orthogonally connected clusters of tiles whose total count matches tile symbol values from your board edge perspective.

Your Turn Options

On each turn, perform one action:

  • Place a Tile: Tap the preview tile to rotate it, then tap an empty cell on the grid.
  • Rotate Existing Tile: Tap a tile on the board to select it, then tap "Rotate Selected Board Tile".

Multi-Perspective Orientations

Each player is assigned to face one of the 4 board edges (Bottom 0°, Left 90°, Top 180°, or Right 270°)!

Because values are computed relative to each player's edge, a single tile represents different numbers to different players simultaneously!

Connected Cluster Matches

Whenever tiles are connected horizontally or vertically, the total count of touching tiles N is calculated.

If a tile's value equals N from a player's perspective edge, that tile clears and awards points to that player!
